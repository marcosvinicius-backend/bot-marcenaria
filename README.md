# 🪵 Bot de Marcenaria

Robô em Python desenvolvido de forma automatizada para otimização e processamento de fluxos de marcenaria.

## 🚀 Tecnologias Utilizadas
* Python
* Python-dotenv (Gerenciamento seguro de chaves de API)
* Telebot / Bibliotecas de automação

## 🔒 Segurança
Este repositório foi configurado seguindo as boas práticas de segurança. Todas as credenciais, tokens e chaves de acesso confidenciais foram ocultadas localmente através do uso de variáveis de ambiente (`.env`), garantindo que dados sensíveis jamais sejam expostos publicamente.

## 🛠️ Como Executar o Projeto
1. Instale as dependências necessárias:
   `pip install python-dotenv`
2. Configure seu arquivo `.env` com os tokens correspondentes.
3. Execute o script principal:
   `python script.py`
